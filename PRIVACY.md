# Package Cleaner — Privacy Policy

*Last updated: October 27, 2026*

**Package Cleaner** is built by **Dima Rud** ([dimarud.com](https://dimarud.com)) with an uncompromising commitment to user privacy. We believe developer tools should respect your machine, your code, and your personal data.

---

### 1. No Data Collection or Tracking
- **Zero Telemetry**: Package Cleaner contains no analytics SDKs, trackers, or usage monitoring.
- **Zero File Scanning Telemetry**: Your file paths, project names, code contents, disk usage numbers, and scan results are processed entirely in memory on your Mac and are **never** uploaded or shared.
- **No Account Required**: You do not need to register, provide an email, or sign in to use Package Cleaner.

### 2. Network Requests
The only network activity initiated by Package Cleaner is:
- **Application Update Check**: To notify you of new features and bug fixes, the app makes an anonymous HTTP GET request to the public GitHub Releases API (`https://api.github.com/repos/dimarud1995/package-cleaner-releases/releases/latest`). No personal identifiers, file data, or tokens are transmitted.
- **Disabling Updates**: You can turn off automatic update checks at any time in **Settings → Check for Updates Automatically**.

### 3. Local Storage
- Application preferences (such as monitored root folders, scan intervals, and clean history) are stored strictly locally on your Mac in `~/Library/Preferences/com.aryze.PackageCleaner.plist` via standard macOS `UserDefaults`.
