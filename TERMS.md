### 2. Local Operation & User Responsibility
- **Local Execution**: Package Cleaner runs entirely on your local machine. It does not transfer your source code, directory structures, file contents, or personal files to external servers.
- **User Validation & Confirmation**: While Package Cleaner employs safety heuristics to categorize disposable build outputs and dependencies, **you remain exclusively responsible for verifying the files and directories selected for deletion**.
- **Trash Bin vs. Direct Deletion**: By default, Package Cleaner moves cleaned files to the macOS system Trash (`~/.Trash`). If you enable the optional setting "Delete Completely (Skip Trash Bin)", deleted items cannot be restored.
